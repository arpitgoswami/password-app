# Password Generator

## Overview
A lightweight, web‑based password generator built with modern front‑end technologies. The app creates strong, randomly generated passwords without requiring any server‑side components, making it ideal for quick, secure credential creation.

## Features
- **Customizable length** – Adjust the number of characters per password.  
- **Character set control** – Enable/disable uppercase letters, lowercase letters, digits, and special symbols.  
- **One‑click copy** – Generated passwords are automatically copied to the clipboard.  
- **Responsive UI** – Clean, mobile‑friendly interface that works on all screen sizes.  
- **Zero dependencies** – Pure HTML, Tailwind CSS, and vanilla JavaScript; no build step or backend needed.
